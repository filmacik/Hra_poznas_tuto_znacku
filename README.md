# Značkovačka

Jednoduchá časovaná hra na hádanie log. Hráč má pri každej z 50 náhodne vybraných značiek 10 sekúnd na odpoveď. Výsledky sa ukladajú lokálne v prehliadači.

## Spustenie cez GitHub Pages

1. Vytvorte nový GitHub repozitár a nahrajte doň súbory `index.html`, `styles.css`, `app.js` a `README.md`.
2. Otvorte v repozitári **Settings → Pages**.
3. Pri **Build and deployment** vyberte **Deploy from a branch**, následne vetvu `main` a priečinok `/(root)`.
4. Uložte. Po krátkej chvíli bude hra dostupná na adrese uvedenej v nastavení GitHub Pages.

Projekt je bez servera a bez inštalácie balíčkov. Logá sa načítavajú z verejného CDN balíka Simple Icons; pri nedostupnom logu sa použije písmenová náhrada.
